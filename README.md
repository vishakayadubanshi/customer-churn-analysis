# 📉 Customer Churn Analysis

Predicting which customers will leave a Telecom company using Machine Learning.

## What This Project Covers
- Overall churn rate analysis
- Churn by gender, contract type, internet service
- Tenure vs churn relationship
- Monthly charges impact on churn
- Logistic Regression ML model with ~80% accuracy
- Confusion matrix and classification report

## Key Business Insights
- 26% of customers churn
- Month-to-month contracts have highest churn
- New customers (tenure < 12 months) are at highest risk
- Higher monthly charges = higher churn rate

## Tools Used
- Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Dataset
- Telco Customer Churn (Kaggle)
